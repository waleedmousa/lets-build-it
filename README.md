# Let's Build It

Code for the **Let's Build It** series on [Runtime Explained](https://www.youtube.com/@runtime_explained).

Each episode builds one real thing in under 3 minutes. Every folder here holds the exact code shown on screen, so you can copy it, run it, and change it.

| Episode | What you build | Folder |
|---|---|---|
| Vector Databases | Search that understands meaning, with Chroma | [`vector-databases/`](vector-databases/) |
| Tiny LLM (EP 10) | A tiny language model in five blocks and 70 lines, then two experiments that break it | [`tiny-llm/`](tiny-llm/) |
| RAG from scratch (EP 11) | Chat with your own documents in one 26-line file, break it, then scale it up as homework | [`rag/`](rag/) |
| Jev hands-on (EP 12) | Sort a support inbox with typed questions: setup, first call, the trap and the fix | [`jev/`](jev/) |
| Snake that teaches itself (EP 13) | An AI that learns Snake by itself in about 50 lines and 2 seconds, two ways to break it, and one upgrade | [`snake/`](snake/) |
| 100 birds that learn to fly (EP 14) | A tiny neural network (25 numbers) trained by evolution in about 60 lines, two ways to break it, and an exam | [`birds/`](birds/) |
| AI image generator (EP 15) | A diffusion model in 74 lines that turns random dots into a picture, two ways to break it, and your own drawing as homework | [`image-generator/`](image-generator/) |
| A tiny Shazam (EP 16) | Name a song from 3 noisy seconds in about 50 lines: picture, dots, pairs, vote. Plus every test from the video and a helper for your own WAV files | [`shazam/`](shazam/) |
| A blockchain you can rob (EP 17) | A working chain in 37 lines with no installs: fingerprints, mining, the check, and three attempts to cheat it | [`blockchain/`](blockchain/) |

## Off the Sheet

A second series on the same channel: one box from a cheat sheet, used for real. The cheat sheet is The Python Line Map.

| Episode | The box | Folder |
|---|---|---|
| 1. We set a trap for an AI | Data Analyst line, stop 7: a join that silently multiplies rows, and `validate="m:1"`, the one argument that stops it | [`off-the-sheet/01-join-trap/`](off-the-sheet/01-join-trap/) |

Bonus (no video): [`off-the-sheet/bonus-load-a-file/`](off-the-sheet/bonus-load-a-file/), stop 1 of the same line: loading a file, real dates, and scanning a 5-million-row file.

## How to use this repo

1. Pick an episode folder.
2. Follow its README. Each one lists the install line, the run command and the output you should see.
3. Swap in your own data.
