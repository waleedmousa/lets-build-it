# Let's Build It

Code for the **Let's Build It** series on [Runtime Explained](https://www.youtube.com/@runtime_explained).

Each episode builds one real thing in under 3 minutes. Every folder here holds the exact code shown on screen, so you can copy it, run it, and change it.

| Episode | What you build | Folder |
|---|---|---|
| Vector Databases | Search that understands meaning, with Chroma | [`vector-databases/`](vector-databases/) |
| Tiny LLM (EP 10) | A tiny language model in five blocks and 70 lines, then two experiments that break it | [`tiny-llm/`](tiny-llm/) |

## How to use this repo

1. Pick an episode folder.
2. Follow its README. Each one lists the install line, the run command and the output you should see.
3. Swap in your own data.
